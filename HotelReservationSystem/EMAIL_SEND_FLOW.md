## ?? DETAILED WALKTHROUGH

### **Complete Example: Sending Invoice to John Doe**

**1. Navigate to Billing Module**
   - Click "Billing" from main menu

**2. Find Customer's Invoice**
   - Scroll to find: Bill ID 100 - John Doe - $250.00

**3. Double-Click the Record**
   - Confirmation dialog pops up

**4. Review Information**
   ```
   Customer: John Doe                    ? Correct
   Email: john.doe@example.com           ? Correct
   Invoice #: 100                        ? Correct
   Amount: $250.00                       ? Correct
   ```

**5. Click "Yes" to Confirm**
   - System generates invoice image
   - Reads SMTP settings from App.config
   - Sends email to john.doe@example.com

**6. Success Message**
   ```
   Invoice successfully sent to john.doe@example.com
   ```

**7. Customer Receives Email**
   ```
   Subject: Invoice #100 - Lodgix Hotel
   
   Dear John Doe,
   
   Thank you for staying with us...
   
   [Invoice attachment included]
   ```

## ?? CONFIGURATION + CONFIRMATION

### **Best Practice Setup:**

1. **Configure App.config once:**
```xml
<add key="SmtpFromEmail" value="hotel@lodgix.com"/>
<add key="SmtpPassword" value="your-app-password"/>
```

2. **Every email send:**
   - System shows confirmation dialog
   - You review and confirm
   - Email sent automatically

**Result:** Fast + Safe! ?
